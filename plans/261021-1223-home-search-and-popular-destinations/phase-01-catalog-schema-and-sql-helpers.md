# Phase 1: Catalog schema and SQL helpers

## Overview

One Flyway migration for the hotel-catalog tables the homepage needs, the `norm()` SQL function, the `Destination`
entity, and a test fixture for building hotels in integration tests.

## Context

- `spring-base/DATABASE-SCHEMA.md`: tables `partners`, `accommodation_types`, `addresses`, `hotels`, `hotel_photos`,
  `room_types`, `room_inventory`, `destinations` (column names, CHECKs, indexes).
- `spring-base/src/main/resources/db/migration/V1__create_user_tables.sql`, `V2__create_product_tables.sql`: style
  (lowercase SQL, `uk_<table>_<col>` constraint names, standard columns).

- Non-functional: `ddl-auto: validate` passes; migration runs on Testcontainers and the local Compose DB (both
  `postgres:18-alpine`, contrib included).

## Implementation Steps

1. **Rollback point**: copy `spring-base/src`, `README.md`, `CLAUDE.md` to the session scratchpad (no git commits).
2. **Migration header + helpers**:
   ```sql
   -- Both are "trusted" extensions since PostgreSQL 13: the database owner can create them without superuser.
   create extension if not exists unaccent;
   create extension if not exists pg_trgm;

   -- Accent-, case- and spacing-insensitive form of a name: norm('  Đà  Nẵng ') = 'da nang'.
   -- Immutable so indexes and generated columns can use it; passing the dictionary explicitly is what
   -- makes unaccent safe to treat as immutable.
   create function norm(value text) returns text
       language sql immutable parallel safe strict
       return lower(regexp_replace(btrim(public.unaccent('public.unaccent'::regdictionary, value)), '\s+', ' ', 'g'));
   ```
3. **Tables, in FK order** (standard columns `id bigint generated by default as identity primary key`,
   `version bigint not null default 0`, `created_at timestamptz not null`, `updated_at timestamptz not null` unless
   noted). Enum-like columns are `varchar(20)` + `check (x in (...))` with UPPERCASE values (matches `@Enumerated(STRING)`,
   like `user_roles.role`). `char(2)/char(3)` become `varchar(2)/varchar(3)` + regex CHECK; `citext` emails become
   `varchar(254)` stored lowercased.
   - `accommodation_types` (code unique, name) + insert reference rows `hotel, resort, apartment, villa, hostel`
     (`created_at/updated_at = now()`).
   - `partners` (legal_name, tax_id, contact_email, phone, commission_rate `numeric(5,2) default 15.00` 0..100,
     status PENDING/APPROVED/SUSPENDED default PENDING, approved_by → users, approved_at, deleted_at).
   - `addresses` (line1, line2, ward, district, city not null, state_province, postal_code, country_code `^[A-Z]{2}$`,
     latitude/longitude `numeric(9,6)` both-or-neither + range CHECKs, google_place_id, formatted, verified_at) and
     ```sql
     create index addresses_place_match on addresses (country_code, coalesce(norm(state_province), ''),
         coalesce(norm(city), ''), coalesce(norm(district), ''), coalesce(norm(ward), ''));
     ```
   - `hotels` (partner_id → partners, accommodation_type_id → accommodation_types, name, slug unique, description
     `text`, star_rating 1..5, address_id unique → addresses, distance_to_center_m, google_place_id unique,
     google_rating `numeric(2,1)` 0..5, google_rating_count, google_synced_at, user_rating_avg `numeric(3,1)` 0..10,
     user_rating_count `default 0`, currency `varchar(3)` (FK later), timezone, check_in_from `time default '14:00'`,
     check_in_until, check_out_until `time default '12:00'`, min_check_in_age `default 18`, phone, email,
     status DRAFT/PENDING_REVIEW/ACTIVE/INACTIVE/SUSPENDED default DRAFT, deleted_at). Indexes:
     `hotels_partner_id_idx`; `create index hotels_name_search on hotels using gin (norm(name) gin_trgm_ops)
     where status = 'ACTIVE' and deleted_at is null;`
   - `room_types` (hotel_id → hotels on delete cascade, name, description, size_sqm, max_adults ≥ 1,
     max_children `default 0` ≥ 0, max_occupancy ≥ max_adults, total_rooms ≥ 0, status (listing values) default DRAFT,
     sort_order, deleted_at) + `room_types_hotel_id_idx (hotel_id) where deleted_at is null`.
   - `hotel_photos` (hotel_id → hotels cascade, room_type_id → room_types cascade null = hotel photo, url
     `varchar(500)`, category, caption, sort_order, is_cover) + `(hotel_id, sort_order)` index +
     `create unique index one_cover_per_hotel on hotel_photos (hotel_id) where is_cover and room_type_id is null;`
   - `room_inventory` — **no id/version**; written only by set-based SQL:
     `room_type_id → room_types cascade, stay_date date, total_rooms ≥ 0, booked_rooms default 0 ≥ 0, is_closed
     default false, updated_at timestamptz not null default now(), primary key (room_type_id, stay_date),
     check (booked_rooms <= total_rooms)` + index on `stay_date`. Comment: a missing row means
     `room_types.total_rooms`, none booked, open.
   - `destinations` (type COUNTRY/CITY/DISTRICT/WARD, name `varchar(150)`,
     `normalized_name text generated always as (norm(name)) stored check (normalized_name <> '')`, slug unique,
     country_code, province_key/city_key/district_key/ward_key `varchar(100) not null default ''`,
     source SYNC/ADMIN default SYNC, hotel_count `default 0` ≥ 0, last_synced_at, google_place_id unique,
     center_lat/center_lng, timezone, image_url `varchar(500)`, featured_rank smallint, deleted_at) + the four
     type/key CHECKs from the schema doc (uppercase type values) + indexes:
     ```sql
     create unique index destination_place_key on destinations
         (country_code, province_key, city_key, district_key, ward_key) where deleted_at is null;
     create index destination_autocomplete on destinations using gin (normalized_name gin_trgm_ops)
         where deleted_at is null and hotel_count > 0;
     create index destinations_featured_rank_idx on destinations (featured_rank) where featured_rank is not null;
     ```
   - Header comment states: names from DATABASE-SCHEMA.md, ids/version/timestamps from this project; FKs to
     not-yet-created tables come with those tables.
4. **Entity `Destination`** (extends `BaseEntity`, `@Getter`, `@NoArgsConstructor(access = PROTECTED)`). Map only
   what this plan uses: type, name, normalizedName, slug, countryCode, the four keys, source, hotelCount,
   lastSyncedAt, imageUrl, featuredRank, deletedAt. Mark columns the sync owns, the generated column and keys
   `insertable = false, updatable = false` (normalizedName) or `updatable = false` (type, slug, countryCode, keys,
   source, hotelCount, lastSyncedAt) so an admin save can never overwrite sync data. Class comment explains the split.
   Domain method `updateDisplay(String name, String imageUrl, Short featuredRank)`: trims name, blank image → null.
   No `create(...)` factory yet (rows are inserted by the sync SQL).
5. **`DestinationRepository extends JpaRepository<Destination, Long>`** with
   `Optional<Destination> findBySlugAndDeletedAtIsNull(String slug)`.
6. **`CatalogFixtures`** (test support, plain class built with `JdbcClient`): helpers that insert a partner, an address
   + hotel (status, accommodation type `hotel`, ratings), room types, inventory rows, a cover photo, and return ids.
   Every name gets a unique suffix (`"Đà Nẵng " + shortId()`, letters+digits only) because the database is shared and
   never rolled back. Sets `created_at/updated_at = now()` explicitly.
7. **Tests** — `DestinationRepositoryTest` (`@IntegrationTest`, autowire `JdbcClient`):
   - `norm()`: `' Đà  Nẵng '` → `da nang`, `'HỒ CHÍ MINH'` → `ho chi minh`, `null` → `null`.
   - inserting a destination via SQL fills `normalized_name`; `findBySlugAndDeletedAtIsNull` loads it with that value.
   - a second non-deleted row with the same place key fails; a CITY row with empty `city_key` fails its CHECK.
8. Run `./mvnw test -Dtest=DestinationRepositoryTest,ProjectApplicationTest`.

## Risk Assessment

- **`unaccent` and `Đ/đ`**: expected in `unaccent.rules`; if the test fails, wrap with `translate(value, 'Đđ', 'Dd')`
  inside `norm()` (add before V3 has run anywhere else).
- **Production DB without CREATE privilege**: both extensions are trusted, but the role still needs CREATE on the
  database. README notes it (phase 5).
- **Generated column + immutable wrapper**: `norm` is schema-qualified (`public.unaccent`), so a dump/restore with a
  different `search_path` still works.
- Rollback: drop the local volume (`docker compose down -v`) or restore the scratchpad copy; V3 has not run anywhere else.
